# FormaPro

Plataforma de cursos profissionalizantes criada com React, TypeScript, Vite e Tailwind CSS.

## Como rodar

```bash
npm install
npm run dev
```

## Rotas principais

- `/` Home
- `/cursos` Catálogo de cursos
- `/curso/:id` Detalhe do curso
- `/my-learning` Área do aluno
- `/learn/:id` Ambiente de aula
- `/login` Login
- `/cadastro` Cadastro
